## Observações de curadoria

- As respostas foram reescritas em linguagem simples; não são transcrições extensas das páginas oficiais.
- Quando a fonte não especifica documentos, a base não inventa uma lista: ela orienta a confirmar com a unidade responsável.
- Datas, documentos exigidos, disponibilidade de viagens e normas locais podem mudar. A fonte oficial deve ser conferida novamente antes de usar a orientação em atendimento real.
- A base é um conjunto de orientações educativas, não uma base de dados pessoais de cidadãos.
